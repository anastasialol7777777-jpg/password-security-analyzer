
# Password Security Analyzer

A beginner Python cybersecurity project that analyzes password characteristics and provides security recommendations.

## Features

- Password length validation
- Uppercase and lowercase letter detection
- Digit detection
- Special character detection
- Common password detection
- Basic security scoring system
- Automatic security recommendations

## Technologies

- Python 3
- Built-in Python functions
- Conditional statements
- Loops and lists

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python password_analyzer.py
```

## Security Note

This project is an educational demonstration.
It does not provide a reliable professional password-strength assessment and does not check breached password databases.

Never enter real personal passwords into this program.
